# Codex review brief — NØX/DRIVE

Review the entire repository as a principal art director, senior frontend engineer, ecommerce UX reviewer and accessibility QA. This is a full-product review, not a diff review.

## Intent

NØX/DRIVE should feel like a premium night-performance instrument: carbon, steel, cold white and flavor-specific signal colors. Its narrative is Signal → System → Frequencies → Loadout. It must not resemble a generic DTC supplement template.

## First pass: audit only

Do not modify files on the first pass. Serve the repository locally and inspect the complete page at 390×844, 768×1024 and 1440×900. Test every flavor, CTA, cart quantity control, remove action, Escape behavior and demo checkout. Check browser console, failed requests, keyboard navigation, visible focus, reduced motion and horizontal overflow.

Pay special attention to:

1. Whether the product images and packaging look credible, premium and artifact-free.
2. Whether every flavor produces a genuinely distinct image, color, copy and state.
3. Whether the first mobile viewport communicates brand, product and action immediately.
4. Whether the composition feels original rather than like stacked generic sections.
5. Typography, spacing, contrast, hierarchy, responsive behavior and information density.
6. Ingredient accuracy, responsible caffeine warnings and fictional-demo disclosure.
7. Semantic HTML, focus management, alt text and cart accessibility.

## Required report

Return findings ordered as Blocker, High, Medium and Polish. Every finding must include evidence: file and line, viewport, exact reproduction steps and expected behavior. Separate objective defects from subjective art-direction recommendations. End with a minimal repair plan in dependency order. Do not praise the page or invent problems to fill categories.

After Gustavo approves the report, implement only the approved fixes, rerun the same matrix and include before/after evidence.
